# Gamers Hub

Four tiny black-and-white browser games, each fully self-contained (one `index.html` per folder — no build step, no server, no dependencies). Open any game's `index.html` directly, or open `arcade-hub/index.html` for a landing page that links to all three.

## Games

- **[arcade-hub](arcade-hub/)** — the landing page linking out to the three games below.
- **[rocket-dodge](rocket-dodge/)** — steer a rocket left/right, dodge or shoot falling aliens, chase powerups.
- **[blocks-and-bounce](blocks-and-bounce/)** — brick breaker with a paddle, 3 layouts, and powerups.
- **[beacon-run](beacon-run/)** — a small original 3-level platformer with a story.

Each game's own README has full controls, scoring, and details.

## Running locally

```bash
git clone https://github.com/Holmes9329/Gamers-Hub.git
cd Gamers-Hub
open arcade-hub/index.html   # or any game's index.html directly
```

No install step — these are plain HTML/CSS/JS files that run straight from disk in any modern browser.
